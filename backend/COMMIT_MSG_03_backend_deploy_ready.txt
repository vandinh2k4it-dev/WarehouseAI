Phát hiện thêm trong lúc xử lý lỗi (CHƯA cần sửa code, chỉ cần cấu
hình trên Railway Dashboard):
Railway hiện dùng builder mặc định "Railpack" (thay thế Nixpacks từ
3/2026) — Railpack KHÔNG đọc file nixpacks.toml (khác định dạng config
hoàn toàn với Nixpacks cũ). File nixpacks.toml vẫn giữ trong repo
(không hại gì, phòng khi sau này đổi builder về Nixpacks cổ điển), 
nhưng để bước ép cài opencv-python-headless (né lỗi thiếu libGL trên
môi trường headless) thực sự có tác dụng, PHẢI đặt biến môi trường
RAILPACK_INSTALL_CMD trực tiếp trên Railway Dashboard > Variables:

  RAILPACK_INSTALL_CMD=pip install -r requirements.txt && pip uninstall -y opencv-python opencv-contrib-python opencv-python-headless && pip install opencv-python-headless==4.10.0.84

Việc này KHÔNG nằm trong code/commit — là bước cấu hình thủ công trên
Railway, ghi lại đây để nhóm nhớ đã làm gì và vì sao.

Việc cần làm sau khi push commit này:
1. Tải carton_counter_best.pt từ Kaggle, đặt vào backend/models/,
   commit riêng (không nằm trong commit này vì file lấy từ máy khác).
2. Đặt RAILPACK_INSTALL_CMD trên Railway Dashboard như trên.
3. Theo dõi lại tab Deployments — build sẽ chạy lại tự động sau push.
